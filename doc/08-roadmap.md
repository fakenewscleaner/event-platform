### 功能

- 首頁：網站入口、使命願景、公佈欄
- 登入／註冊、角色 seed
- 登入首頁：近期活動、報名／取消
- 近期活動：清單、卡片、行事曆三種呈現；篩選
- 活動詳情：查看活動、查看志工組成（Admin / Core / 總召）
- 活動詳情編輯：系統自有欄位可編輯，Airtable 欄位唯讀
- 我的活動頁：我的活動、最近統計數字（寫死公式）

### P0 完成定義

- `docker compose up` 後可以跑完整流程。
- Airtable 同步可以排程執行，並正確對應 [04-airtable-sync.md](04-airtable-sync.md) 的欄位。
- 權限矩陣中標 P0 的項目都有 Feature test。

## P1：回報、講師費、總召、物資、行銷、後台

- 回報模組：回饋填寫、照片上傳、成果回報、瀏覽成果
- 後台：管理回饋欄位、物資類型、使用者列表、使用者與權限、通知列表
- 總召：我負責的場次、瀏覽／匯出志工名單
- 講師：講師回報頁（講師費狀況）
- 物資：提出物資需求
- 行銷：文章列表、新增／編輯、刪除
- 志工行為守則頁
- 建立活動（仍從 Airtable）、匯出活動

## P2：通知與進階功能

- 活動詳情「發佈更新」，自動通知所有報名志工（站內 → Email → LINE）
- 地區下一層行政區
- 物資需求審核流程
